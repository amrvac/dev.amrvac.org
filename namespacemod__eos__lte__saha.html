Detailed Description

Analytic hydrogen Saha EoS with neutral helium (eos_method == 'analytic').

Ground-state Saha for hydrogen, solved per call without tables: X(T) = saha_pf * T^{3/2} * exp(-chi/kB/T) y(=ne/nH) = 2X / (X + sqrt(X^2 + 4 nH X)) Public entry points take and return code units; the CGS conversion is internal. T(nH, eint/nH) is found by bisection and p(nH, T) closes the state. build_gamma1_analytic_table tabulates Gamma_1(nH, p/nH) once for the 'exact' gamma1 path, on the axes that gamma1_from_nH_p reads for every method
